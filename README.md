# 自动回复质量评估流水线

> 晓多科技 AI测评 Task 0109 - 自动回复质量评估流水线

## 项目简介

本项目实现了一套客服自动回复质量评估流水线，将业务方模糊的评估需求（"准确、有用、语气好、不瞎编"）转化为可运行的自动化评估方案。通过对 20 条自动回复的逐条评分，生成完整的评估报告，并与人工标注数据进行交叉验证。

## 指标定义及理由

从业务方的 4 个模糊需求中提炼出 5 个可量化评估指标：

| 指标 | 对应业务需求 | 量表 | 权重 | 选择理由 |
|------|-------------|------|------|----------|
| M1 准确性 | 准确 | 1-5 | 0.25 | 错误信息直接误导用户操作，是回复质量的基石 |
| M2 有用性 | 有用 | 1-5 | 0.30 | 人工标注分析显示最高频问题是"正确但没用"，权重最高 |
| M3 语气与共情 | 语气好 | 1-5 | 0.20 | 客服场景用户常带负面情绪，恰当共情提升感知 |
| M4 无幻觉 | 不瞎编 | 0/1 | 0.10(否决) | 编造信息直接损害用户权益，设为否决性指标 |
| M5 主动服务 | 有用(延伸) | 1-5 | 0.15 | 人工与自动回复最大差距：人工主动帮、自动推用户 |

### 指标优先级

1. **无幻觉（最高）**：编造信息直接损害用户权益，一旦出现总分上限降为50%
2. **准确性（高）**：错误信息误导用户操作
3. **有用性（高）**：不解决问题的回复无价值
4. **主动服务（中）**：影响用户感知但不直接造成损失
5. **语气与共情（中）**：影响体验但非核心诉求

## 评估方法

### 评估架构

```
数据加载 → 指标评分 → 加权计算 → 交叉验证 → 报告生成
```

### 支持两种模式

1. **Mock 模式（默认）**：基于领域专家对 20 条 case 的逐条分析，预置评分结果。无需 API Key，直接运行。评分依据：对比 auto_replies.json 与 human_ref.json，结合 eval_criteria.md 中的业务需求。

2. **LLM 模式**：调用 OpenAI 兼容 API（如 DeepSeek），通过标准化 Prompt 模板实现自动评分。使用方式：
```bash
python main.py --mode llm --api-key YOUR_KEY --api-base https://api.deepseek.com/v1 --model deepseek-chat
```

### 加权评分公式

```
base_score = Σ(metric_normalized × weight) / Σ(weight) × 100
# metric_normalized = (score - 1) / 4  (将1-5映射到0-1)

# 幻觉否决机制
if M4 == 0: final_score = min(base_score, 50)
```

## 运行方式

```bash
# Mock 模式（默认，无需额外配置）
python main.py

# LLM 模式（需配置 API Key）
python main.py --mode llm --api-key YOUR_API_KEY

# 指定数据目录和输出目录
python main.py --data-dir ./data --output-dir ./results
```

### 最差 3 条 Case

| 排名 | Case | 得分 | 核心问题 |
|------|------|------|----------|
| 1 | case_20 | 26.4 | 用户说退货流程太复杂，回复又重复了一遍流程，答非所问 |
| 2 | case_13 | 31.9 | 用户说皮肤敏感需要成分信息，回复让用户自己看详情页 |
| 3 | case_01 | 44.4 | 快递放错柜用户取不到，回复把责任推给用户 |

### 主要发现

1. **"正确但没用"是最高频问题**：多数回复信息准确但缺乏针对性
2. **缺乏主动服务意识**：频繁让用户"查看详情页""联系客服"
3. **负面情绪场景处理不足**：用户生气/焦虑时缺乏共情
4. **无幻觉问题**：20条回复中未检测到幻觉

## 局限性讨论

1. **Mock 模式的主观性**：预置评分基于人工分析，存在主观偏差。改进：接入真实 LLM API
2. **业务上下文依赖**：准确性评分依赖业务规则知识，可能不准确。改进：接入知识库
3. **有用性评估的 case-by-case 差异**：同一回复对不同用户有用性不同
4. **语气评估粒度不足**："礼貌"和"共情"难以用单一指标区分
5. **幻觉检测覆盖有限**：对微妙幻觉（过度承诺等）可能漏检
6. **样本量限制**：20条样本统计代表性有限，建议至少200条
7. **缺乏多轮对话评估**：未考虑上下文连贯性等
